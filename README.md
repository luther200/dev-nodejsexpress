# dev-nodejsexpress

personnal dev express website with GET POST DELETE methods.

## Installation: 

```diff
> git clone https://github.com/luther200/dev-nodejsexpress
> cd dev-nodejsexpress
> 
> npm i
> added 92 packages, and audited 93 packages in ...s

> npm run real
    RUNNING IN REAL MODE
    Server started on : http://localhost:8000
    

> npm run dev  
    RUNNING IN DEV MODE (nodemon)
    Server started on : http://localhost:8000
```
